- `curiosity-cabinet.webp`: 1440px hero still life; `curiosity-cabinet-small.webp`: 800px responsive variant.

Render beautiful realistic glass caustics and bronze botanical detail. Output only artwork, no website mockup, no text, no watermark."

Fern prompt: "Production website editorial botanical background, no text or typography. Wide landscape 3:2 macro nature photograph style of a fresh green fern frond with tiny dew drops, backlit by warm morning sunlight.
